Java Low-Level Design (LLD)

A hands-on repository documenting my journey in Low-Level Design using Java, Object-Oriented Programming, SOLID principles, design patterns and practical system-design problems.

🎯 Objectives

- Build strong object-oriented design fundamentals.
- Understand relationships between classes and objects.
- Apply SOLID principles to create maintainable and extensible software.
- Implement design patterns using real-world examples.
- Practice interview-oriented LLD problems through Java implementations.
